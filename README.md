## 🧰 How a game gets onto the site

1. A developer packages a static HTML5 build as a ZIP — it only has to contain an `index.html`.
2. The uploader unpacks it, generates the thumbnail automatically and tags it with a category.
3. Machine checks run first, a human spot-checks after — most games go live within 24 hours.
4. Each published game gets its own SEO page (`/games/<slug>`) and starts earning ad revenue.
5. Players open the page and the game runs inside a **sandboxed iframe**, so it never touches
   personal data.

## 💰 Developer program

From [https://pipygames.com/developers](https://pipygames.com/developers):

- **50% revenue share** on the ad revenue your games generate, **70%** during a new developer's launch period.
- **Net-45 payouts** — revenue is settled monthly and paid on a Net-45 cycle.
- **12-point credit system** — every developer starts with 12 credit points; staying compliant keeps them, and they unlock faster reviews and better exposure.
- **~24h average review time.**

There is also **Share & Earn** ([https://pipygames.com/share](https://pipygames.com/share)): share a
personal link for any game, and when a friend plays it and watches one short rewarded ad you get
coins plus cash credit (~$0.10 per valid conversion, $10 minimum withdrawal). Self-referrals and
repeat visits from the same browser don't count.

## 🛠️ Under the hood (overview)

The portal is a single full-stack **Next.js 14** app — public game pages and the admin dashboard
ship from the same codebase. Game metadata, uploads and accounts sit behind **Prisma**, auth runs on
**NextAuth**, and an automated pipeline (headless browser + image processing) produces thumbnails,
covers and gameplay GIFs for each upload so a submitted ZIP needs no marketing assets of its own.
Games are embedded as-is in a sandboxed iframe and share one in-house SDK for domain authorization,
rewarded/interstitial ads and event tracking.
